# 上海高考 · 升学坐标

一个基于浏览器的交互式上海高考与美术艺考升学辅助工具。

输入文化成绩和美术统考成绩，即可对照 2025 年上海普通高考与美术艺考相关投档数据，了解分数位置、院校专业组和目标院校要求。

## 在线体验

- 原项目地址：https://github.com/bulagedidan0124-cell/shanghai-gaokao-map
- 在线版本：https://shanghai-gaokao-map.vercel.app

## 功能

### 普通高考路径

根据文化成绩浏览普通本科批院校及专业组信息，包括：

- 院校投档分数
- 专业组数量
- 专业组代码
- 学校办学性质
- 多个专业组的投档分数范围

### 美术艺考路径

根据艺考综合分查看艺术类院校和专业组，包括：

- 艺考综合分
- 院校专业组投档线
- 美术专业分参考值
- 2025 年参考位次
- 各专业组详细录取信息

### 目标院校反推

选择一个艺术类目标院校专业组，系统会根据当前成绩反推：

- 达到目标投档线所需的文化分
- 达到目标投档线所需的美术专业分
- 当前成绩是否超过对应满分限制

### 其他功能

- 支持滑块和数字输入两种成绩设置方式
- 支持普通模式和详细模式切换
- 支持移动端浏览
- 支持减少动画偏好
- 对部分浏览器提供 WebMCP 工具调用能力

## 综合分计算

项目使用页面中的 2025 年参考计算方式：

```
艺考综合分 = 文化分 × 0.5 + 美术专业分 × 1.1
```

例如：

```
文化分 470 + 美术专业分 250
综合分 = 470 × 0.5 + 250 × 1.1
       = 510.00
```

## 使用范围

当前成绩输入范围为：

| 成绩项目 | 范围 |
| --- | --- |
| 文化成绩 | 302–660 分 |
| 美术专业成绩 | 180–300 分 |

其中，文化成绩的最低值 302 分对应页面所使用的艺术类本科文化线参考值。

## 本地运行

这是一个无需构建工具的纯前端静态项目。

### 方式一：直接打开

克隆仓库后，直接使用浏览器打开根目录中的 `index.html`。

### 方式二：使用本地静态服务器

推荐使用静态服务器运行，以确保本地数据脚本能够正常加载。

```bash
git clone https://github.com/dhammanaga/shanghai-gaokao-map.git
cd shanghai-gaokao-map
python -m http.server 8000
```

然后在浏览器中打开：

```
http://localhost:8000
```

如果使用原始仓库：

```bash
git clone https://github.com/bulagedidan0124-cell/shanghai-gaokao-map.git
```

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构、元信息和脚本入口 |

| `src/data/extraction-report-2025.json` | 数据提取记录和校验报告 |

## 数据来源

项目数据主要参考：

- 上海市教育考试院发布的 2025 年相关投档文件
- 教育部 2025 年全国高校名单及学校信息

数据文件中的部分记录保留了原始文件名和页码信息，便于后续核对。

## 数据限制

请注意：

- 项目使用的是 2025 年历史参考数据
- 部分普通高考投档线仅公布为 580+
- 数据不代表 2026 年或其他年份的实际录取结果
- 计算结果不考虑未来招生计划、报考人数、政策变化和专业组调整
- 反推结果仅为等值计算，不构成录取建议或录取承诺
- 填报志愿时应以官方最新招生政策、招生计划和投档数据为准

## 开发说明

项目采用原生前端技术实现：

- HTML
- CSS
- JavaScript
- JSON

项目没有使用前端框架或第三方运行时依赖。数据通过 `index.html` 中的脚本标签加载：

```html
<script defer src="./src/data/admission-bundle-2025.js"></script>
<script defer src="./src/app.js"></script>
```

如需更新数据，应优先修改 `src/data` 下的 JSON 源文件，并同步更新浏览器使用的 `admission-bundle-2025.js` 文件。
